# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 主边同票（边表事务外置修复）

病灶：装载服务曾先提交主表（观测报文）再在事务外插边表（入栏缓冲/坏点匣），断连后留"主表绿、边表空"半态，校验只看主表 → 账实撕裂假绿。

落点择定 **切流账册** 形态（非双写两轨）：

- **主边同事务落定**：主表命运与边表行同成同败；边表失败整票回滚，主表零残留、不写装载批次、不亮成功（`services/装载.py`，单报文 SAVEPOINT 隔离撞键）。
- **半态可区分**：`services/同票.py` 扫描主有边无/边有主无；人为掐断边表插入后页灯转红、回刷被拒（`拒半态回刷`）。
- **贯验拒假绿**：半态计入撕裂，半态主表不得当对齐绿（`services/贯验.py`）。
- **切流账册**：耐久指纹（非 `stale-fp`）+ `active_read=cutover_book`；双写两轨不启用、不翻读轨。
- **五页可见**：报文流列表、入栏缓冲详情、探栏台卡片、栏贯验策略页、站点汇总账均渲染主边同票条/同票列。

测试：`tests/test_edgeout_1.py`（装载假绿）、`test_edgeout_2.py`（贯验假绿）、`test_edgeout_3.py`（断连重试/并发双态/拒回刷），先红后绿。并发争用脚本：`scripts/并发争用.py`。
